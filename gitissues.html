¿Qué son los Issues en GitHub?

Los issues son una herramienta fundamental en GitHub para rastrear tareas, mejoras, bugs y cualquier tipo de trabajo relacionado con un proyecto. Funcionan como un sistema de tickets que permite la colaboración y organización del equipo.

Casos de uso principales:
  • Reportar bugs: Documentar errores encontrados en el código
  • Solicitar features: Proponer nuevas funcionalidades
  • Hacer preguntas: Consultas sobre el proyecto
  • Documentar tareas: Organizar el trabajo del equipo
  • Discusiones técnicas: Debatir sobre implementaciones

Componentes de un Issue

Título

Descripción breve y clara del problema o tarea

Descripción

Detalles completos, pasos para reproducir, capturas

Labels

Etiquetas para categorizar (bug, enhancement, etc.)

Assignees

Personas responsables de resolver el issue

Milestone

Agrupación por versión o sprint

Comments

Discusión y actualizaciones sobre el issue

Crear Issues desde la Interfaz Web

Método: Interfaz Gráfica

La forma más sencilla y visual de crear un issue es directamente desde la interfaz web de GitHub.

Pasos para crear un Issue

Acceder al Repositorio

Navega al repositorio donde deseas crear el issue en GitHub.com

Ir a la pestaña Issues

Haz clic en la pestaña "Issues" en la parte superior del repositorio

Crear Nuevo Issue

Haz clic en el botón verde "New issue"

Completar el Formulario

Añade un título descriptivo y una descripción detallada usando Markdown

Configurar Metadatos

Opcionalmente, asigna labels, assignees, projects y milestones

Enviar el Issue

Haz clic en "Submit new issue" para crearlo

Consejos Pro:
  • Usa Markdown: Formatea tu issue con encabezados, listas, código, etc.
  • Incluye contexto: Versión del software, sistema operativo, pasos para reproducir
  • Adjunta screenshots: Arrastra y suelta imágenes directamente
  • Referencias: Menciona otros issues con #número o usuarios con @nombre
  • Templates: Usa plantillas de issue si el repositorio las tiene configuradas

# Script para crear issue desde errores en logs

LOG_FILE="app.log"
ERROR_COUNT=$(grep "ERROR" $LOG_FILE | wc -l)

if [ $ERROR_COUNT -gt 10 ]; then
  ERRORS=$(grep "ERROR" $LOG_FILE | tail -10)
  gh issue create \
    --title "⚠️ Múltiples errores detectados en producción" \
    --body "Se detectaron $ERROR_COUNT errores en las últimas horas:\n\n\`\`\`\n$ERRORS\n\`\`\`" \
    --label "bug" \
    --label "urgent"
fi

import requests
import json

# Configuración
GITHUB_TOKEN = "ghp_tu_token_personal"
REPO_OWNER = "usuario"
REPO_NAME = "mi-proyecto"

# Headers con autenticación
headers = {
    "Authorization": f"token {GITHUB_TOKEN}",
    "Accept": "application/vnd.github.v3+json"
}

# URL de la API
url = f"https://api.github.com/repos/{REPO_OWNER}/{REPO_NAME}/issues"

# Datos del issue
issue_data = {
    "title": "Feature Request: Modo oscuro",
    "body": """## 🎨 Descripción
Implementar un modo oscuro para mejorar la experiencia de usuario.

## 📝 Requisitos
- [ ] Toggle en configuración
- [ ] Persistir preferencia del usuario
- [ ] Aplicar a todas las vistas
- [ ] Transición suave entre modos

## 🎯 Beneficios
- Reduce fatiga visual
- Ahorra batería en dispositivos OLED
- Mejora accesibilidad
    """,
    "labels": ["enhancement", "ui/ux"],
    "assignees": ["nombre-usuario"]
}

# Realizar petición POST
response = requests.post(url, headers=headers, json=issue_data)

# Verificar respuesta
if response.status_code == 201:
    issue = response.json()
    print(f"✅ Issue creado exitosamente!")
    print(f"📊 Número: #{issue['number']}")
    print(f"🔗 URL: {issue['html_url']}")
    print(f"📅 Creado: {issue['created_at']}")
else:
    print(f"❌ Error al crear issue: {response.status_code}")
    print(f"Mensaje: {response.json()['message']}")

Script de Automatización Avanzado

Python - Bot de Issues 
from github import Github
import os
from datetime import datetime, timedelta

class IssueBot:
    def __init__(self, token, repo_name):
        self.g = Github(token)
        self.repo = self.g.get_repo(repo_name)
    
    def create_weekly_report_issue(self):
        """Crea un issue semanal con reporte de actividad"""
        # Obtener estadísticas de la semana
        week_ago = datetime.now() - timedelta(days=7)
        
        # Contar PRs mergeados
        merged_prs = 0
        for pr in self.repo.get_pulls(state='closed'):
            if pr.merged and pr.merged_at > week_ago:
                merged_prs += 1
        
        # Contar commits
        commits = self.repo.get_commits(since=week_ago)
        commit_count = commits.totalCount
        
        # Crear reporte
        report = f"""# 📊 Reporte Semanal - {datetime.now().strftime('%Y-%m-%d')}

## 📈 Actividad de la Semana
- **Commits:** {commit_count}
- **Pull Requests Mergeados:** {merged_prs}
- **Contributors Activos:** {len(set(c.author.login for c in commits if c.author))}

## 🎯 Próximos Objetivos
- [ ] Revisar issues pendientes
- [ ] Actualizar documentación
- [ ] Planificar próximo sprint

---
*Generado automáticamente por IssueBot 🤖*
        """
        
        issue = self.repo.create_issue(
            title=f"📊 Reporte Semanal - {datetime.now().strftime('%d/%m/%Y')}",
            body=report,
            labels=['report', 'weekly']
        )
        
        return issue
    
    def create_stale_issues_reminder(self):
        """Crea issue recordando issues sin actividad"""
        month_ago = datetime.now() - timedelta(days=30)
        stale_issues = []
        
        for issue in self.repo.get_issues(state='open'):
            if issue.updated_at < month_ago:
                stale_issues.append(f"- #{issue.number} - {issue.title}")
        
        if stale_issues:
            body = f"""# ⏰ Issues Sin Actividad Reciente

Los siguientes issues no han tenido actividad en más de 30 días:

{chr(10).join(stale_issues[:20])}

{'...' if len(stale_issues) > 20 else ''}

**Total:** {len(stale_issues)} issues

Por favor, revisar y actualizar el estado de estos issues.
            """
            
            issue = self.repo.create_issue(
                title="⏰ Recordatorio: Issues sin actividad reciente",
                body=body,
                labels=['maintenance', 'reminder']
            )
            
            return issue
        return None

# Uso
if __name__ == "__main__":
    TOKEN = os.getenv("GITHUB_TOKEN")
    REPO = "usuario/proyecto"
    
    bot = IssueBot(TOKEN, REPO)
    
    # Crear reporte semanal
    weekly = bot.create_weekly_report_issue()
    print(f"✅ Reporte semanal creado: {weekly.html_url}")
    
    # Crear recordatorio de issues obsoletos
    stale = bot.create_stale_issues_reminder()
    if stale:
        print(f"✅ Recordatorio creado: {stale.html_url}")
    else:
        print("ℹ️  No hay issues sin actividad")

Bot Automatizado con GitHub Actions

JavaScript - Bot 
const { Octokit } = require("@octokit/rest");

class GitHubIssueBot {
  constructor(token, owner, repo) {
    this.octokit = new Octokit({ auth: token });
    this.owner = owner;
    this.repo = repo;
  }

  /**
   * Crea issue de reporte diario
   */
  async createDailyReport() {
    const today = new Date().toISOString().split('T')[0];
    
    // Obtener estadísticas del día
    const stats = await this.getDailyStats();
    
    const body = `# 📊 Reporte Diario - ${today}

## 📈 Actividad del Día
- **Issues Abiertos:** ${stats.openedToday}
- **Issues Cerrados:** ${stats.closedToday}
- **Pull Requests:** ${stats.prs}
- **Commits:** ${stats.commits}

## 🔥 Issues Más Activos
${stats.hotIssues.map(i => `- #${i.number} - ${i.title} (${i.comments} comentarios)`).join('\n')}

## 👥 Contributors
${stats.contributors.map(c => `- @${c.login} (${c.contributions} contribuciones)`).join('\n')}

## 🎯 Próximas Tareas
- Revisar PRs pendientes
- Actualizar documentación
- Responder issues sin respuesta

---
*🤖 Generado automáticamente*
    `;

    const issue = await this.octokit.rest.issues.create({
      owner: this.owner,
      repo: this.repo,
      title: `📊 Daily Report - ${today}`,
      body,
      labels: ['report', 'automated']
    });

    return issue.data;
  }

  /**
   * Obtiene estadísticas del repositorio
   */
  async getDailyStats() {
    const today = new Date();
    today.setHours(0, 0, 0, 0);

    // Issues abiertos hoy
    const openIssues = await this.octokit.rest.issues.listForRepo({
      owner: this.owner,
      repo: this.repo,
      state: 'open',
      since: today.toISOString()
    });

    // Issues cerrados hoy
    const closedIssues = await this.octokit.rest.issues.listForRepo({
      owner: this.owner,
      repo: this.repo,
      state: 'closed',
      since: today.toISOString()
    });

    // Issues más comentados (últimos 7 días)
    const weekAgo = new Date(today);
    weekAgo.setDate(weekAgo.getDate() - 7);
    
    const recentIssues = await this.octokit.rest.issues.listForRepo({
      owner: this.owner,
      repo: this.repo,
      state: 'open',
      since: weekAgo.toISOString(),
      per_page: 100
    });

    const hotIssues = recentIssues.data
      .sort((a, b) => b.comments - a.comments)
      .slice(0, 5)
      .map(i => ({
        number: i.number,
        title: i.title,
        comments: i.comments
      }));

    return {
      openedToday: openIssues.data.length,
      closedToday: closedIssues.data.length,
      prs: 0, // Implementar si necesitas
      commits: 0, // Implementar si necesitas
      hotIssues,
      contributors: [] // Implementar si necesitas
    };
  }

  /**
   * Crea issues desde un archivo de tareas
   */
  async bulkCreateFromTasks(tasks) {
    const results = [];
    
    for (const task of tasks) {
      try {
        const issue = await this.octokit.rest.issues.create({
          owner: this.owner,
          repo: this.repo,
          title: task.title,
          body: task.body,
          labels: task.labels || [],
          assignees: task.assignees || []
        });
        
        results.push({
          success: true,
          number: issue.data.number,
          url: issue.data.html_url
        });
        
        console.log(`✅ Creado: #${issue.data.number}`);
      } catch (error) {
        results.push({
          success: false,
          error: error.message,
          task: task.title
        });
        console.error(`❌ Error en: ${task.title}`);
      }
    }
    
    return results;
  }
}

// Uso
async function main() {
  const bot = new GitHubIssueBot(
    process.env.GITHUB_TOKEN,
    "usuario",
    "proyecto"
  );

  // Crear reporte diario
  const report = await bot.createDailyReport();
  console.log(`📊 Reporte creado: ${report.html_url}`);

  // Crear múltiples issues desde lista
  const tasks = [
    {
      title: "Implementar cache de Redis",
      body: "Agregar capa de cache para mejorar performance",
      labels: ["enhancement", "performance"]
    },
    {
      title: "Actualizar dependencias",
      body: "Actualizar todas las dependencias a últimas versiones",
      labels: ["maintenance"]
    }
  ];

  const results = await bot.bulkCreateFromTasks(tasks);
  console.log(`✅ ${results.filter(r => r.success).length}/${tasks.length} issues creados`);
}

main().catch(console.error);
