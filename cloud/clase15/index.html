¿Y si la nube estuviera en localhost?

Concepto

¿Qué es un emulador?

Un programa que imita la interfaz de otro sistema, de modo que lo que funciona con el original funciona igual con él.

Simulador de vuelo

Mismos controles y mismos instrumentos. El avión no despega, pero el piloto aprende igual.

Emulador de Android

Probás tu app en un “teléfono” que en realidad es un programa en tu PC.

Floci

Responde las mismas llamadas que AWS. Tu código cree que habla con Amazon.

Idea clave: el programa cliente no se entera de que no es AWS real. Solo cambia la dirección a la que envía los pedidos.

Presentando

¿Qué es Floci?

  • Emulador de AWS gratuito y de código abierto, con licencia MIT.
  • Imita 119 servicios: S3, EC2, Lambda, DynamoDB, RDS, SQS, IAM y muchos más.
  • Corre como un contenedor Docker y atiende todo en el puerto 4566.
  • No pide cuenta, token ni registro. No envía telemetría.
  • Es compatible con LocalStack: mismo puerto, mismos protocolos.
  • Arranca en milisegundos y ocupa poca memoria en reposo.
¿por qué “Floci”?

Cirrocumulus floccus

Es un tipo de nube formado por copos pequeños y livianos. El nombre describe el proyecto: una nube chiquita que entra en tu computadora.

El proyecto también tiene versiones para Azure, GCP y Oracle Cloud.

Puesta en marcha · 1/2

Instalar y arrancar

Requisitos: Docker Desktop en ejecución y AWS CLI v2.

Opción A · CLI de Floci (PowerShell)
# Instalar la herramienta
iwr https://floci.io/install.ps1 | iex

# Arrancar el emulador
floci start

# Ver estado y diagnóstico
floci status
floci doctor
Opción B · Docker directo
docker run -d --name floci `
  -p 4566:4566 `
  -v /var/run/docker.sock:/var/run/docker.sock `
  floci/floci:latest

# Comprobar que está corriendo
docker ps

El volumen docker.sock le permite a Floci crear contenedores. Sin él no hay instancias EC2, ni Lambda, ni RDS.

EC2 · conceptos

Una instancia, pieza por pieza

instancia

Un servidor virtual que alquilás por hora. Es el corazón de EC2.

AMI

La imagen de disco con la que arranca: sistema operativo y software preinstalado.

tipo de instancia

Su tamaño en CPU y memoria. Por ejemplo, t2.micro tiene 1 vCPU y 1 GiB.

key pair

Par de claves para entrar por SSH sin contraseña.

security group

Reglas que dicen qué puertos aceptan conexiones y desde dónde.

VPC y subred

La red privada donde vive la instancia y su rango de direcciones IP.

user data

Un script que se ejecuta automáticamente al arrancar la instancia.

IMDS

Servicio interno que le cuenta a la instancia quién es: ID, IP, región.

EC2 · detrás de escena

En Floci, cada instancia es un contenedor

Al ejecutar run-instances, Floci lanza un contenedor Docker real usando la imagen que corresponde a la AMI pedida.

AMI (alias)Imagen Docker
ami-amazonlinux2023amazonlinux:2023
ami-amazonlinux2amazonlinux:2
ami-ubuntu2404ubuntu:24.04
ami-ubuntu2204ubuntu:22.04
ami-debian12debian:12
ami-alpinealpine:latest

AMI desconocida

Si pedís una AMI que Floci no conoce, usa Amazon Linux 2023.

Red lista para usar

Ya existen vpc-default, las subredes subnet-default-a/b/c y el grupo sg-default.

Límites reales

El contenedor recibe la CPU y memoria del tipo de instancia elegido.

EC2 · ciclo de vida

Cada estado de EC2 es una operación de Docker

Acción en EC2Transición de estadoQué hace Docker
run-instancespending → runningcreate + start
stop-instancesrunning → stopping → stoppeddocker stop
start-instancesstopped → pending → runningdocker start
reboot-instancesrunning → runningdocker restart
terminate-instancesrunning → shutting-down → terminateddocker rm -f

Igual que en AWS, una instancia terminada sigue apareciendo en las consultas durante una hora.

Lab EC2 · Claves y security group

PowerShell
# 1. Par de claves: la privada se guarda en lab-key.pem
aws ec2 create-key-pair --key-name lab-key `
  --query KeyMaterial --output text | Out-File -Encoding ascii lab-key.pem

# 2. Security group en la VPC por defecto (guardamos su ID)
$SG = aws ec2 create-security-group --group-name web-sg `
  --description "Lab web" --vpc-id vpc-default `
  --query GroupId --output text

# 3. Abrir el puerto 80 a cualquier origen
aws ec2 authorize-security-group-ingress --group-id $SG `
  --protocol tcp --port 80 --cidr 0.0.0.0/0

En Floci, abrir un puerto TCP en el security group hace que ese puerto se publique en tu máquina, en el rango 30000–30999.

Lab EC2 · Script de arranque

bootstrap.sh
#!/bin/bash
dnf install -y nginx
echo "<h1>Hola desde $(hostname)</h1>" \
  > /usr/share/nginx/html/index.html
nginx

Qué hace

Instala nginx, escribe una página con el nombre del equipo y arranca el servidor web.

¿Por qué nginx y no systemctl?

El contenedor no tiene systemd, así que el servicio se lanza directamente.

Importante en Windows: guardá el archivo con fin de línea LF. En VS Code se cambia abajo a la derecha (CRLF → LF). Con CRLF, Linux no reconoce la primera línea y el script falla.

Lab EC2 · Lanzar la instancia

PowerShell
$ID = aws ec2 run-instances `
  --image-id ami-amazonlinux2023 `
  --instance-type t2.micro `
  --count 1 `
  --key-name lab-key `
  --security-group-ids $SG `
  --user-data file://bootstrap.sh `
  --query "Instances[0].InstanceId" --output text

$ID   # muestra algo como i-0a1b2c3d...

# Consultar estado e IP privada
aws ec2 describe-instances --instance-ids $ID `
  --query "Reservations[0].Instances[0].[State.Name,PrivateIpAddress]"

La AWS CLI codifica el user data en base64 por nosotros, tal como lo exige la API de EC2.

EC2 · por dentro de la instancia

Entrar y preguntarle quién es

PowerShell → dentro de la instancia
# Ubicar el contenedor de la instancia
docker ps

# Abrir una terminal adentro
docker exec -it <id-del-contenedor> bash

# Ya adentro: consultar el IMDS
curl http://169.254.169.254/latest/meta-data/instance-id
curl http://169.254.169.254/latest/meta-data/instance-type
curl http://169.254.169.254/latest/meta-data/local-ipv4
curl http://169.254.169.254/latest/user-data
169.254.169.254

Es la misma dirección del servicio de metadatos en AWS real. Floci la emula, con IMDSv1 y con IMDSv2 (por token).

¿y SSH?

Floci copia la clave pública al contenedor e intenta arrancar sshd, pero las imágenes base no lo traen instalado. Para usar SSH hay que instalarlo en el script de arranque.

Lab EC2 · Detener y eliminar

PowerShell
# Detener (el contenedor se apaga, no se borra)
aws ec2 stop-instances --instance-ids $ID

# Volver a encenderla
aws ec2 start-instances --instance-ids $ID

# Eliminarla definitivamente
aws ec2 terminate-instances --instance-ids $ID

# Borrar la red y la clave
aws ec2 delete-security-group --group-id $SG
aws ec2 delete-key-pair --key-name lab-key

En AWS real, olvidarse este paso cuesta dinero. Acá no cuesta nada, pero conviene practicar el hábito de limpiar.

Para no frustrarse

Límites a tener presentes

IPs privadas inaccesibles desde Windows

Con Docker Desktop, el navegador no llega a la IP del contenedor. Se entra por el puerto publicado en localhost.

El security group no es un firewall

Por defecto Floci lo usa para publicar puertos, pero no bloquea el tráfico entre instancias.

Escuchar en 0.0.0.0

Si la aplicación escucha solo en 127.0.0.1, el reenvío de puertos no la alcanza.

Puertos después de un stop

Al detener una instancia se pierde la publicación del puerto. Al arrancarla, hay que volver a autorizar la regla o recrear la instancia.

Consumo de recursos

Cada instancia, Lambda o base de datos es un contenedor más. Conviene apagar lo que no se usa.

Es una sola máquina

No hay zonas de disponibilidad reales: la alta disponibilidad solo se puede modelar, no probar.
