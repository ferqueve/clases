PARTE A · UBUNTU SERVER

Hardware y disco

Memoria y CPU

Mínimo recomendado: 4GB de RAM y 2 procesadores. Pueden subir si la máquina física lo permite.

Disco

50GB alcanza de sobra para esta prueba — disco virtual dinámico, no reservado por completo.

Terminen el asistente y entren a la configuración de la VM antes de arrancarla, para dejar la red bien definida primero.

PARTE A · UBUNTU SERVER

Configurar la red

Si están en su red doméstica: Adaptador Puente sobre la tarjeta de red conectada a internet, con Modo Promiscuo en "Permitir todo" — así la VM obtiene una IP real de la red, visible desde el equipo anfitrión.

Adaptador Puente = la VM se comporta como si fuera "otra PC más" conectada al mismo router, con su propia IP. Es distinto del modo NAT, donde la VM queda escondida detrás del equipo anfitrión.
PARTE A · UBUNTU SERVER

Instalación guiada

Instalación mínima

No necesitamos paquetes extra para este laboratorio — elegí la opción mínima del instalador.

IP manual

Configurá una IP fija dentro del rango de tu red (ej. 192.168.5.90/24), con el gateway correspondiente.

Usuario y contraseña

Elegí sus propias credenciales — es importante recordarlas, las van a usar todo el laboratorio.

OpenSSH

Marquen instalar OpenSSH al final del instalador, para poder conectarse luego por Putty/SSH.

Para liberar el mouse de la ventana de VirtualBox: Ctrl derecho.

PARTE B · NEXTCLOUD

A partir de acá trabajamos sobre Ubuntu Server 22.04. NextCloud necesita un servidor web, PHP y una base de datos — vamos a usar Apache + MariaDB.

 actualizar

sudo apt upgrade
 dependencias

php-common php-curl php-gd php-imap php-intl php-json php-mbstring php-mysql \
php-xml php-zip unzip -y
PARTE B · NEXTCLOUD

Crear la base de datos

 entrar a MariaDB
sudo mysql -u root -p
# como todavía no seteamos contraseña de root, la dejamos vacía al pedirla
# (esto NUNCA debe quedar así en un servidor de producción)
 dentro de MariaDB
create database nextcloud;
create user 'ncuser'@'localhost' identified by 'unaClaveSegura123';
grant all privileges on nextcloud.* to 'ncuser'@'localhost';
flush privileges;
quit
PARTE B · NEXTCLOUD

Descargar e instalar NextCloud

 descargar y ubicar
wget https://download.nextcloud.com/server/releases/nextcloud-24.0.1.zip
unzip nextcloud-24.0.1.zip
sudo mv nextcloud /var/www/html
 permisos
sudo chown -R www-data:www-data /var/www/html/nextcloud
sudo chmod -R 755 /var/www/html/nextcloud
Estos dos comandos le dicen al servidor web (usuario www-data) que es dueño de esos archivos y puede leerlos/escribirlos — sin esto, NextCloud no puede ni arrancar.
PARTE B · NEXTCLOUD

Configurar Apache

 /etc/apache2/sites-available/nextcloud.conf
<VirtualHost *:80>
DocumentRoot /var/www/html/nextcloud/
ServerName localhost
<Directory /var/www/html/nextcloud/>
Options +FollowSymlinks
AllowOverride All
<IfModule mod_dav.c>
Dav off
</IfModule>
SetEnv HOME /var/www/html/nextcloud
SetEnv HTTP_HOME /var/www/html/nextcloud
</Directory>
ErrorLog ${APACHE_LOG_DIR}/nextcloud_error.log
CustomLog ${APACHE_LOG_DIR}/nextcloud_access.log combined
</VirtualHost>
 activar sitio y módulos
sudo a2ensite nextcloud.conf
sudo a2enmod rewrite headers env dir mime setenvif
sudo a2dissite 000-default.conf
sudo service apache2 restart
PARTE B · NEXTCLOUD

Asistente web y cuenta admin

Entrando a la IP de la VM desde el navegador, completá el asistente: usuario y contraseña de administrador, y los datos de la base de datos que creaste antes (nextcloud / ncuser / localhost).

Cuenta admin

Usuario y contraseña de administrador de NextCloud (distinto del usuario del sistema operativo).

Datos de BD

Nombre de la base, usuario, clave y host — los mismos que definiste con MariaDB.

Apps recomendadas

Al finalizar, podés instalar las apps sugeridas (Calendar, Contacts, Talk) o dejarlo para el ejercicio siguiente.

PARTE B · NEXTCLOUD

La herramienta para el ejercicio: occ

occ es la CLI de administración de NextCloud — permite gestionar usuarios, apps y configuración sin pasar por el navegador. Se ejecuta como el usuario del servidor web.

 ejemplo: listar apps instaladas
sudo -u www-data php /var/www/html/nextcloud/occ app:list
Ejercicio práctico

Habilitar un servicio real por CLI

Vamos a activar la app de Calendario de NextCloud sin usar el navegador — así se hace en un despliegue real automatizado.

Si calendar no está disponible en tu instalación (a veces falla si no hay salida a internet hacia la tienda de apps), usá cualquiera de estas alternativas — el ejercicio las acepta igual: contacts, tasks o notes.

Escribí el comando occ para habilitar la app calendar (o una de las alternativas de arriba), ejecutado como www-data, apuntando al occ de /var/www/html/nextcloud.

Ejercicio práctico

Verificar que quedó activa

Escribí el comando para listar las apps instaladas y confirmar que calendar aparece como habilitada.
