Práctica guiada

De tu código a la nube local

Desplegá una aplicación Node.js en Dokku mediante Git.

Objetivo

Crear, versionar, desplegar, comprobar y actualizar una aplicación web. Al final entregarás un documento con capturas y explicación de los pasos.

Trabajo individual o en parejas

01 · Conceptos

¿Qué es PaaS?

Vos

Escribís el código y hacés git push.

Dokku

Construye y ejecuta la aplicación usando contenedores.

Nginx

Recibe solicitudes HTTP y las dirige a la aplicación.

PaaS = Platform as a Service. En este laboratorio, la plataforma se ejecuta en una VM del docente.

02 · Topología

¿Cómo funciona nuestro laboratorio?

PC del estudiante

Git + Node.js

Red local universitaria

VM Ubuntu Server

SSH → Dokku → Docker → Nginx → navegador

La IP puede cambiar al trasladar la VM. No utilizaremos una IP fija en los comandos.

03 · Red

Identificá la IP del servidor

Docente: en la VM ejecutá:

hostname -I

Elegí la dirección IPv4 de la interfaz conectada a la red universitaria (no la IP de Docker 172.17.x.x).

Se usa para personalizar los comandos de las siguientes diapositivas. No se envía a ningún servidor.

04 · Conectividad

¿Podés llegar al servidor?

Estudiante, desde PowerShell:

Test-NetConnection IP_SERVIDOR -Port 22

Resultado esperado: TcpTestSucceeded : True.

Si falla: verificar IP, adaptador puente de VirtualBox, firewall y aislamiento entre clientes Wi-Fi. No continúes hasta resolver la conectividad.

05 · Preparación docente

Crear una aplicación en Dokku

El docente crea una app por estudiante o equipo, con nombre y puerto propios. Ejemplo:

dokku apps:create alumno1 dokku domains:set alumno1 IP_SERVIDOR dokku ports:set alumno1 http:8081:5000 dokku ports:report alumno1

Usar puertos libres y diferentes: 8081, 8082, 8083... El puerto interno 5000 corresponde a nuestro ejemplo Node.js.

Nota: los cambios de puerto pueden requerir reconstruir la configuración de Nginx después del despliegue. Verificar con dokku proxy:build-config alumno1.

06 · Seguridad del laboratorio

Acceso para desplegar

El docente administra la VM. El estudiante necesita autorización SSH para enviar código a Dokku.

ssh-keygen -t ed25519 Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub

En PowerShell, enviá al docente solo la clave pública (.pub), nunca la privada.

Docente: guardá la clave pública en un archivo del servidor y ejecutá dokku ssh-keys:add equipo1 /ruta/equipo1.pub.

Importante: Dokku no limita automáticamente cada clave a una sola app. Usar un servidor de laboratorio aislado, aplicaciones de prueba y supervisión. No compartir la contraseña root.

07 · Código

Creá el proyecto Node.js

En PowerShell:

mkdir mi-app-dokku cd mi-app-dokku npm init -y npm install express

Creá un archivo server.js con el código de la próxima diapositiva.

08 · Código

Programá el servidor HTTP

const express = require('express'); const app = express(); const port = process.env.PORT || 5000; app.get('/', (req, res) => { res.send('<h1>¡Hola desde Dokku!</h1><p>Mi primera aplicación PaaS</p>'); }); app.listen(port, '0.0.0.0', () => { console.log(`Escuchando en ${port}`); });

La aplicación escucha en todas las interfaces del contenedor. PORT permite adaptar el puerto.

09 · Ejecución

Configurá el comando de inicio

En PowerShell, dentro del proyecto:

npm pkg set scripts.start="node server.js" npm start

En otra terminal, abrí http://localhost:5000. Deberías ver ¡Hola desde Dokku!.

Detené el proceso con Ctrl + C antes de continuar.

10 · Git

Versioná el proyecto

git init git add . git commit -m "Primera versión" git branch -M main
Buenas prácticas: creá un archivo .gitignore que contenga node_modules/ antes de git add .. Si Git pide identidad, configurá user.name y user.email.

11 · Despliegue

Enviá tu código a Dokku

git remote add dokku dokku@IP_SERVIDOR:alumno1 git push dokku main

Esperá a que finalice la construcción y el despliegue. Si la app usa una rama distinta, adaptá el comando.

Si aparece Permission denied (publickey), revisá la clave SSH autorizada. No uses la contraseña de root.

12 · Verificación

¡Abrí tu aplicación!

Desde cualquier equipo de la red que tenga acceso al servidor:

http://IP_SERVIDOR:8081

El docente asignará el puerto de cada equipo.

Si no responde, el docente puede ejecutar:

dokku ps:report alumno1 dokku logs alumno1 --tail dokku ports:report alumno1

13 · Actualización

Modificá y volvé a desplegar

Cambiá el mensaje HTML en server.js. Luego ejecutá:

git add . git commit -m "Actualizo mensaje de bienvenida" git push dokku main

Recargá el navegador. ¿Ves el nuevo mensaje? ¡Acabás de realizar un segundo despliegue!
